# ChatToDesign v2

Новая версия находится в ветке `codex/plugin-v2` и папке `v2`. Корневые `manifest.json`, `main.js`, `ui.html` и старые архивы сохранены без изменений. История v2 хранится отдельно от истории v1.

## Запуск в Pixso

1. Подключите **`v2/manifest.json`** как отдельный локальный плагин. У него отдельные имя и ID: `ChatToDesign · v2`.
2. Запустите `node v2/gigachat-bridge.mjs`. Если прежний мост уже работает, можно использовать его; второй процесс на том же порту не нужен.
3. Выберите размер формы. Плагин автоматически поставит LightBox. При ошибке появится «Повторить попытку».
4. Введите код подключения из терминала в поле «Токен GigaCode CLI» и опишите задачу.
5. Проверьте компоненты, удалите лишние или отправьте задачу на доработку. Подтвердите набор.
6. Согласуйте свойства каждого компонента. Превью показано слева и автоматически обновляется после изменения свойств (пауза 300 мс при вводе). «Назад» сохраняет черновик и возвращает к предыдущему компоненту, а с первого — к набору.
7. В финальном наборе «Назад» открывает свойства последнего компонента. «Поставить на макет» вставляет согласованные экземпляры.

Этап состояний и ошибок не включён в UI v2. Библиотека Triplex и авторизация GigaCode CLI требуются как в прежней версии. Код локального моста не сохраняется в истории.

## Макеты

Источник: [Figma](https://www.figma.com/design/SyMMFR1cBGIDu5Z5b3xYQ2/Untitled?node-id=1-2).
Реализованы компоненты Select, Text Field, Text Area Field и Button, включая loading, и экраны выбора размера, задачи, предложения, доработки, свойств и итогового набора. В свойства добавлена обязательная область живого превью из Pixso. Шрифты SB Sans используются при наличии в системе, иначе Arial.

## Проверка

Из корня проекта:

```sh
node --test tests/workflow.test.cjs tests/v2-workflow.test.cjs
node tests/v2-ui-smoke.cjs
```

Второй сценарий требует Playwright и установленный Google Chrome. Он проверяет реальный DOM и переходы с подставными ответами Pixso: выбор размера, повтор установки, загрузку, подбор, доработку, запрос превью, подтверждение и возврат. Скриншоты сохраняются во временные файлы `/tmp/v2-*.png`.

Интеграционная проверка реальной библиотеки и вызовов CLI выполняется в Pixso; автоматические проверки используют заглушки API.
