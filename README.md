# Triplex в Pixso с GigaCode CLI

Плагин ставит LightBox из подключённой библиотеки Triplex. GigaCode CLI предлагает поля, а плагин вставляет их экземпляры в выбранную область после подтверждения.

## Запуск на рабочем компьютере

1. В уже работающем проекте Pixso замените корневой `main.js` и `ui/ui.html` файлами из этой папки. Скопируйте `gigachat-bridge.mjs` рядом с `package.json`. Используйте конфигурацию и манифест вашего проекта.
2. Проверьте, что установленный CLI доступен в терминале. Плагин рассчитан на [GigaCode CLI](https://gitverse.ru/docs/ai/ai-assistant-gigacode/gigacode-cli/). Для проверки выполните `gigacode -p "Ответь словом OK" --output-format json`. Ожидается JSON с полем `result`. Авторизация выполняется в самом CLI.
3. В одном терминале оставьте `npm run dev`, во втором запустите `node gigachat-bridge.mjs`. Скопируйте код подключения из второго терминала в плагин. Это код локального моста, он меняется при перезапуске. Мост слушает только `127.0.0.1:43127`, а запрос передаётся в CLI через аргумент `-p`.
4. Поставьте LightBox и выделите внутренний фрейм с автолейаутом. Если выделен сам LightBox, плагин ищет единственный `BodyPage` среди первых двух уровней.
5. Опишите задачу и нажмите «Предложить компоненты». Плагин подбирает кандидатов из библиотеки установленного LightBox по именам и группам. Для набора вариантов он использует вариант по умолчанию.
6. Проверьте компоненты, подписи и фрейм назначения. Нажмите «Подтвердить и вставить». Если у компонента нет однозначного текстового свойства, подпись сохраняется как имя слоя.

[Storybook Triplex](https://triplex-design.ru/next/ru/Web) и [исходники Triplex Next](https://github.com/SberBusiness/triplex-next) описывают назначение и поведение компонентов. Плагин получает экземпляры и свойства через каталог Pixso. Подсказки для модели ограничены типовыми элементами формы.

Если CLI отвечает из терминала, а окно Pixso не подключается, проверьте разрешение редактора или браузера на доступ к локальной сети. Плагин отправляет описание задачи и имена и назначение предложенных компонентов. Учётные данные GigaCode остаются в CLI.

## Сценарий из бизнес-требований

1. Поставьте LightBox. Откройте «Бизнес-требования и сценарий», вставьте текст требований и применимые правила [текстового стандарта Triplex](https://triplex-design.ru/next/ru/Super/Text/release%20notes).
2. Нажмите «Отправить». Ответьте на вопросы модели или уточните порядок состояний в поле сообщения. Последний предложенный сценарий используется при подборе компонентов.
3. Проверьте условия, моковые значения и тексты ошибок. Нажмите «Утвердить состояния и ошибки». Правка требований, стандарта или сообщения сбрасывает утверждение.
4. Соберите первый экран и внесите ручные правки на холсте. Нажмите «Утвердить экран и создать состояния». Плагин создаст рядом подписанные копии текущего экрана и заполнит вымышленными значениями поля с доступным текстовым свойством Value. Условия веток и утверждённые тексты ошибок видны в чате. Тексты ошибок сохраняются в данных соответствующих фреймов для ручного оформления. Переключение вариантов компонентов и отдельные экраны с другой структурой пока не поддерживаются.
